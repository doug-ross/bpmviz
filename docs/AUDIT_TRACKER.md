# Audit tracker

Status of every item in the September 2026 AIxRay audit (`docs/audit/AIxRay_Audit.md`), plus the three requests that came with it: Sogeti styling, an AI-tell cleanup, and a better README.

Status values: **Done**, **Partial** (a first increment ships; the note says what is left), **Deferred** (not built; the note says why).

Test names refer to `tests/unit/*.test.mjs` (`npm test`, 270 tests) and `tests/browser/*.test.mjs` (`npm run test:browser`, 64 tests that run the app in Chrome from disk, over HTTP and with the local AI helper). `npm run check` runs the Sogeti anti-style gate and the prose check. `npm run smoke:ai` is a manual check on a real Claude Code or Codex sign-in.

## Architecture and workflow recommendations (audit sections 2, 5 and 6)

| Recommendation | Status | Notes |
|---|---|---|
| Converge on the v2 renderer; keep gateway and event semantics | Done | Layout, routing, text fitting and navigator ported from v2; `gatewayP` and `gatewayX` keep their meaning as parallel and exclusive gateways. |
| No browser feature that runs uploaded JavaScript | Done | Legacy files are converted in Node (`npm run convert`); the app only reads JSON and BPMN XML. |
| One generator contract; retire the older prompts | Done | New prompt in `tools/prompts/`; the three old prompts carry an archived notice. |
| Module boundaries; separate business data from view state | Done | `webui/js/lib/` (model and logic, also used by the Node tests) and `webui/js/ui/`. Pan, zoom, selection and the playhead never create a revision. |
| Layered validation with field paths; errors and warnings kept apart | Done | `validate.js`. |
| Explicit file save as the durable contract; local recovery as a safety net | Done | Drafts use `localStorage` in both deployment modes (an engagement is a few hundred KB). An IndexedDB adapter can replace it behind the same interface if files grow. |
| Security boundary: data not code, safe sinks, no outbound connections | Done | See P0-07. The optional AI helper serves the page with `connect-src 'self'` and accepts only same-origin requests with a session token, on 127.0.0.1 (P2-02). |
| Modular vanilla JavaScript; dev-only test toolchain; static distributable | Done | No framework and no build step; `playwright-core` and `pdfjs-dist` are the only dev dependencies, used by the tests and the AI tools. The app itself has no dependencies. |
| Few connected workspaces rather than separate apps | Done | Process, Records, Value and Present on one engagement. Value is shown because it works for current-state-only engagements too. |
